Configuration options

Every option of the configuration file, with its default. weed config prints the same, as a configuration file, and this page is made from it. Without a configuration file, weed uses these defaults except server.address = "127.0.0.1" and server.anonymous = true (see Configuration).

Paths are used as written: relative ones are relative to the directory weed starts in. Durations are strings such as "90s", "10m" or "24h".

Sections: [server], [tls], [x509], [basic], [oidc], [macaroons], [tokens], [tpc], [unix_users], [admin].

[server]

Server. See Configuration.

Option Default Meaning
address "" Address to listen on ("" for all interfaces).
port 9000 TCP port.
dir "." Directory exported under /webdav/.
anonymous false Serve requests without credentials as the Unix account nobody; only on a loopback address (the default without a configuration file).
log_file "" Log to this file ("" for standard error); weed reopens it on SIGHUP, for logrotate.
log_level "info" Log records of this level and above: "debug", "info", "warn" or "error".
log_format "text" "text" (key=value) or "json", one record per line.
metrics_address "" Serve Prometheus metrics (/metrics), what runs (/status) and /healthz, without authentication, on this address, e.g. "localhost:9100" ("" disables).
reload_interval "1h" Re-read credential files (htpasswd, app tokens, grid-mapfile, CAs, CRLs, token issuers, TLS certificate) this often ("0s": only on SIGHUP).

[tls]

HTTPS. See Installation.

Option Default Meaning
enabled false Serve HTTPS.
cert "server.crt" Server certificate (PEM).
key "server.key" Its private key (PEM).

[x509]

X.509 client certificates and proxies (needs tls). See Authentication.

Option Default Meaning
enabled false Accept X.509 client certificates.
ca "" CA certificates: a PEM file, or a directory such as /etc/grid-security/certificates.
crl_path "" Certificate revocation lists: a file or a directory such as /etc/grid-security/certificates, kept current by fetch-crl ("" accepts revoked certificates).
crl_mode "require" "require" rejects certificates whose issuer has no current CRL; "if-valid" only checks against the CRLs that are present and current.
gridmap "/etc/grid-security/grid-mapfile" Grid-mapfile: only certificates whose DN it lists are accepted, as its usernames.

[basic]

HTTP Basic authentication with passwords and app tokens (weed utils password, weed utils token). See Authentication.

Option Default Meaning
enabled false Accept Basic authentication.
htpasswd ".htpasswd" Htpasswd file (bcrypt).
app_tokens ".app-tokens" App tokens file.

[oidc]

A login page for browsers (/auth/oidc) that gives out WLCG tokens: users log in at a token issuer listed in tokens.issuers, and get the access token it issues, to use as a bearer token. See Authentication.

Option Default Meaning
enabled false Serve the login page.
issuer "" Issuer URL, as in tokens.issuers, e.g. "https://wlcg.cloud.cnaf.infn.it/".
client_id "" Client ID.
client_secret "" Client secret.
redirect_url "" Redirect URL, e.g. "https://weed.example.org/oidc_redirect".
scopes ["openid", "storage.read:/"] Scopes to ask for, e.g. ["openid", "storage.read:/", "storage.modify:/"]; the issuer grants those its policies allow.
audience "" Audience to ask for (the "audience" parameter of INDIGO IAM), one of the issuer's audiences in tokens.issuers ("": the issuer's default).

[macaroons]

Macaroons: bearer tokens that weed mints (POST with Content-Type application/macaroon-request). See Authentication.

Option Default Meaning
enabled false Accept and mint macaroons.
secret_key "" Signing key, at least 32 characters.
location "weed-webdav" Location identifier.
max_validity "24h" Maximum (and default) lifetime of minted macaroons.

[tokens]

WLCG and SciTokens JWT bearer tokens. See Authentication.

Option Default Meaning
issuers "" Accept tokens from the issuers in this JSON file ("" disables): [{"issuer": "https://...", "audiences": ["https://this.server"], "base_path": "/", "users": [{"sub": "...", "group": "/vo/group", "user": "account"}]}].
ca_path "" Extra CA certificates (file or directory) for fetching the issuers' signing keys, in addition to the system roots.

[tpc]

WLCG HTTP third-party copy (COPY with Source, or with a remote Destination). See Third-party copy.

Option Default Meaning
enabled false Serve third-party copies.
ca_path "" Extra CA certificates (file or directory, e.g. /etc/grid-security/certificates) for verifying remote endpoints, in addition to the system roots.
allow_http false Allow plain-text http:// remote endpoints.
allow_local false Allow remote endpoints on loopback and link-local addresses (testing only).
allow_private false Allow remote endpoints on private addresses (RFC 1918, RFC 4193, shared address space).
max_transfers 32 Maximum number of concurrent copies.
marker_interval "5s" Interval between performance markers.
stall_timeout "2m" Abort a copy that transfers no data for this long ("0s" disables).

[unix_users]

Unix accounts: every request accesses files as the Unix account its credentials map to (anonymous ones: nobody), from a worker process running as that account; an identity without an account gets 403. weed runs on Linux, as root (or with CAP_SETUID and CAP_SETGID). See Unix accounts.

Option Default Meaning
idle_timeout "10m" Stop the worker process of an account once it has served no request for this long.
max_workers 256 At most this many worker processes take requests; once they are all busy, requests of other accounts get 503.
max_requests 4000 At most this many requests in progress in each worker process, counted until the worker has finished them, also once their clients have gone; beyond, requests of its account get 503. A request whose storage does not answer blocks a thread of the worker until it does.
cgroups false Run each worker process in a cgroup of its own, below weed's, which must be delegated to weed (systemd: Delegate=yes); cgroup v2.
cgroup_limits [] Write these file=value settings to the cgroup of every worker process, e.g. ["memory.max=8G", "pids.max=5000"] (implies cgroups); pids.max counts threads, and a worker that cannot make one dies: keep it above max_requests.

[admin]

The control plane: a Unix socket that weed utils talks to (ban, unban, bans), which only root and weed's own user can use. See Banning users.

Option Default Meaning
socket "/run/weed/admin.sock" Its path ("" disables); weed creates the directory, which only its owner may enter, if missing.
bans "/var/lib/weed/bans.json" The users banned with weed utils ban, which weed refuses (403) whatever their credentials, are kept in this file across restarts ("": until weed stops); weed writes it, and reads it at startup.
